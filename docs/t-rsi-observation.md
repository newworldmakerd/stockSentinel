# 双周期 RSI 做 T 观察

2026-10-21，按用户确认实现。参数属于待回测规则，不能称为已验证的最优策略。只提醒、不下单；未改变公共买卖、缩量回踩、个人价位或仓位计算。

## 规则与范围

| 条件 | 动作 |
|---|---|
| 15分钟 Wilder RSI(14) > 50 且 5分钟 RSI(14) > 80 | 高位减仓观察 |
| 15分钟 RSI(14) < 50 且 5分钟 RSI(14) < 20 | 低位买入观察；已有实际减仓申报则为回补观察 |
| 14:50起，已申报买卖股数不相等 | 提醒人工恢复底仓；不依赖行情成功、不自动执行 |

只处理已配置群内、本人当日申报的正持仓，且明确申报可卖数量大于0。没有加入公共关注名单也能参与；同一股票行情复用，群和用户的持仓、成交、通知独立。跨日可卖数量按既有仓位规则失效，需重新申报；不会自动把昨日持仓全部当作今日可卖。

开新观察时间为10:00–11:30、13:00–14:50（14:50不含）；开盘前30分钟、午休不发新观察。依赖现有每分钟扫描，5分钟K线更新才重判。每股、每群、每用户、每方向每天最多一次；买卖两侧都已记录成交后，不再开新一轮。恢复底仓每天提醒一次，仅针对实际已申报的净差额；未申报成交不推定用户已经执行提醒。

这里明确以“高RSI减仓、低RSI买入/回补”命名，不依赖容易混淆的正T、反T术语。新规则替代之前尚未实现的“成本上方2%＋前一分钟高低点＋净价差1%”方案，未暗中叠加那些过滤条件。费用和滑点仍需人工考虑，不据RSI保证净收益。

## 行情与计算契约

`GET /internal/indicators/t-rsi?symbol=000731`（Python内部接口）。从现有AKShare适配器取近30自然日的5分钟**前复权**历史，同一序列聚合15分钟收盘；RSI只使用收盘序列。不填午休、隔夜的虚构K线；缺少本应存在的5分钟K线后重新预热。至少15根完整15分钟收盘用于初始化RSI14，数据不足返回422，来源异常返回502。没有给新历史接口添加腾讯后备，不会把原来的腾讯1分钟后备误称为覆盖本接口。

响应包含 `symbol/source/adjustment/period/observed_at/five_at/fifteen_at/rsi5/rsi15`。RSI值区间0–100；全平收盘返回50，纯上涨100，纯下跌0；Wilder以最初14个价差算术平均初始化，再按1/14平滑。仅使用结束时间严格早于计算时点的完整K线。按股票和5分钟时间槽缓存，最多256条；不会逐用户重复拉取。

Java校验来源、复权类型、周期、指标范围、时间对齐与新鲜度，分钟参考价仍使用现有不复权快照；RSI价格不拿去和持仓成本混算。没有实时有效数据则不发建议，扫描日志保存 `T_RSI_HTTP_*`、`T_RSI_STALE_OR_INVALID`、`T_RSI_PRICE_NOT_ALIGNED` 等原因，不将失败当成规则不匹配。模型只查询最近落库状态，不主动补造报价。

## 群聊使用

```text
@股票助手 记录四川美丰持仓800股，成本7.8元，可卖800股
@股票助手 查看四川美丰做T状态
@股票助手 记录四川美丰做T卖出成交200股，成交价8元
@股票助手 记录四川美丰做T买入成交200股，成交价7.8元
```

新增受控工具 `get_t_observation(stock_query)` 和 `record_t_fill(stock_query,side,quantity,price)`。身份只来自企微回调，不接受模型传入group/user；成交命令必须整条文字符合上述形式，数量和人民币价格必须逐字匹配。问题、否定、假设、代他人、追加混合指令不写入。群助手查询不会立即调用行情。

首版每方向每天只允许**一次汇总成交申报**；不支持分笔累加、撤销和纠错。第一笔需有对应观察；恢复方向可在用户真实成交后申报。数量不超过当日建立观察时的可卖底仓上限，已有另一方向成交时也不能超过该方向数量。缺少总资金不会给出买入股数；可卖上限不是建议全部卖出的数量。

成交只写手工台账，不改券商或系统仓位；请独立更新实际仓位。若建立观察后更新了仓位，当日该股自动RSI观察暂停，避免错误复用原基准；已申报成交仍保留，14:50仍检查净差额。下一交易日重新申报后建立新观察。部分成交或成交记录错误需要人工核验处理，系统不能保证收盘恢复成功。

## 持久化、投递与开启

V17新增 `t_observation_day`、`t_observation_receipt`、`t_observation_notice`，不修改已执行迁移。观察状态、通知元数据、既有notify_record出站队列同事务保存。按日/群/用户/股票/方向幂等；同一消息成交去重。过期、仓位或成交变化的待发提醒过期处理；收盘后不补发，14:50后不补发开新观察。UNKNOWN不盲重发，明确可重试结果最多3次，仍发本人所属群并标注用户。

