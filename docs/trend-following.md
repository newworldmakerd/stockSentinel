## 用户确认的规则

- 日线前复权：C>MA60、MA60>MA120、MA60(t)>MA60(t-20)，同时满足；MA20仅展示。
- 收盘突破此前20根最高价，不含当日；成交额≥5000万元；排除ST、无成交、异常/涨停报价。下一开市日才观察执行，不假设按信号收盘价买入。
- 盘中使用上一开市日准备的趋势底座和包含该日的最近20根通道，当前报价突破只发预告，正式确认使用完整且人工确认的当日日线。
- 严格大盘过滤：已确认的沪深300收盘价>MA200才允许新观察；相等、下方、缺数据都暂停新观察，不关闭持仓风控。实时指数只提示偏离，不能替代已确认收盘过滤。
- ATR14为14个TR的简单平均，非Wilder。初始止损=实际买价−2×入场前已确认ATR（留存快照）。每个实际买入批次独立跟踪；最高收盘价仅用入场以来完整日线，止损=max(旧止损,最高收盘−3×当日ATR)，只上移，次一交易日才用于盘中判断。
- 日内价格触及旧止损发醒目风险观察，不能保证成交；T+1、本人当日可卖、跳空与跌停限制保留。不自动下单。
- 计划股数按单笔风险0.5%、单股上限10%、组合上限80%三者及资金余量取最小，普通股票按100股向下取整，科创板不足200股不形成计划。账户权益、组合市值、该股市值和计划价格必须明确申报；缺失/过期不猜。

## 边界

Java负责规则、调度、历史采集入库、信号和通知、群身份及个人账本；Python只标准化行情及计算MA/ATR/通道，不连接数据库。
独立全市场历史准备与报价扫描，不在每分钟重拉5000只股票历史。准备和扫描有预算、进度及安全错误码；盘中预告/收盘确认每股每日各一次，大盘状态改变才提醒；个人止损按批次每日一次。
复权序列全窗同源；指标按当日不复权参考价换算后才能用于实际价格止损。报价前收与缓存原收盘不一致时，视为除权或口径待核对，暂停相关判断，不擅自调整历史止损。
手工买入可以多批次；卖出必须指定本人的批次编号，不自动猜FIFO或把提醒当成交；只由明确成交命令更新个人聚合仓位。新买入不增加当日可卖，不自动推算跨日可卖。
板块相对强度未指定周期和来源，首版不虚构板块排名，不改变基础条件。

## 新接口（契约）

- Python POST `/internal/trend/calculate`：已确认同源QFQ/NONE日线输入，返回版本化MA20/60/120、20日MA60变率、ATR14及前20/最近20日通道，含原价换算与窗口摘要。
- Python GET `/internal/trend/index?as_of=...`：固定沪深300日线，不与000300个股混用；当前日需Java确认参数。
- Python POST `/internal/trend/quotes`：限定沪深代码/沪深300，返回原价、前收、累计成交额、成交量、涨跌停价、真实时间；失败独立列出。
- Java GET `/api/v1/trend`：开关、参数、底座覆盖、指数状态及最近扫描。
- Java POST `/api/v1/trend/prepare`、`/scan`：默认dryRun；明确false才采集/写入/入通知队列。
- 群工具：记录趋势账户、查询趋势状态/自己的批次、风险股数试算、记录趋势买入、按批次记录卖出。身份绑定群+回调用户，每条消息最多一次写入，字面值复核。

新增V22迁移，保持已有V1—V21不改。真实接口、迁移运行库、重启启用及主动测试推送另需授权。

```text

计划四川美丰趋势买入，计划价8元，已有该股市值0元
```

买卖记录必须来自实际手工成交，123替换为本人的批次编号；按群和回调用户隔离。买入更新现有个人聚合持仓及加权成本，新买不增加当日可卖；原做T模块仍遵守持仓变更校验。账户快照跨日或记录趋势成交后失效，重新申报后才能再次试算数量。原持仓不会自动变为趋势批次。

## 数据与启用边界

趋势报价使用腾讯适配，沪深300日线使用东方财富适配，股票日线复用现有Java采集及QFQ/NONE缓存。真实核验已获得三项报价、两股各486条QFQ/NONE日线与沪深300的486条日线；指数源随后发生连接中断，缺基准时严格暂停新增观察并15分钟后重试，不能宣称接口已稳定。

原价和前复权历史起点不同时，仅裁去两者共同起点之前的数据；窗口内部日期、顺序、来源等校验仍保留，不通过取日期交集丢弃中间缺口。

历史准备每批最多20股，轮次预算45秒；报价每批最多100股，一分钟调度，持仓优先，再轮转全市场。预算阻止启动下一项，不强制中断在途请求。首次历史补齐可能较慢，状态接口展示覆盖情况，不能承诺每分钟完整覆盖全市场。

当日日线仍需人工收盘确认；沪深300分别绑定源 `TREND_CSI300_EASTMONEY`、`TREND_CSI300_TENCENT`。只确认一源时只请求该源；两源都确认时可当日自动切换。未确认不发正式信号。除权口径不符的批次进入BASIS_REVIEW，需人工核对，不自动降低止损。

本机已设置 `TREND_ENABLED=true`、`TREND_SCHEDULE_ENABLED=true`，无需Docker。默认参数见 `.env.example`。运行库已执行V21、V22，文档模块保持关闭。每次规则扫描不调用大模型；群内自然语言操作沿用原助手工具。
