# 个人仓位记录与规则提示

## 1. 背景与目标

用户确认按群+企微userid+股票保存持股数量、成本价、可卖数量。公共信号不改，后续已落库的买卖/风险规则生成独立个人仓位约束提示；不按持仓人数调用大模型，不自动下单。

## 2. 使用与影响点

在已配置群里@机器人：

- 记录亨通光电持仓1000股，成本50元，可卖500股
- 设置四川美丰仓位2000股，成本7.2元
- 查看我的仓位
- 结合我的仓位分析亨通光电
- 记录亨通光电持仓0股

正持仓必须明确成本人民币元；可卖未提供则未知。每次设置为完整申报，未给可卖不会沿用旧值。股数只接受整数股，不换算手数或百分比。记录0股表示手工申报空仓，省略成本；不是发送清仓订单。

持股与成本保留到下次申报，可卖股数只在申报当日视为有效，跨日变未知，不自动推算T+1。申报不是券商真实持仓，成交后需自己更新。查询本人在当前群的仓位，每页20只，不支持替他人读写。仓位记录不自动增加公共关注，若需监控该股票，应另行明确关注。

修改点：V16 personal_position；personal包PositionMapper/Service/Delivery；GroupAssistantTools与DeepSeekGroupAssistantClient新增set_position/list_my_positions/get_position_advice；NotificationService的规则信号事务中按群入队。

## 3. 规则与通知

- BUY_WATCH/BREAKOUT_WATCH/PULLBACK_STRENGTH：区别空仓与已有持仓，已有持仓不代表必须追加买入；缺少资金总额、目标比例时不生成买入数量。
- SELL_WATCH/RISK_ALERT/STOP_LOSS/TAKE_PROFIT/RAPID_DROP：有持仓则提示当日申报可卖上限；可卖0明确无已确认可卖量，可卖未知/跨日先核实，不能把全部持仓当可卖。空仓不建议卖出。
- 成本用于计算规则参考价相对申报成本的价格差，标明非实时收益、不含费用及分红送转成本修订；不改变MACD、均线、价格阈值或原始信号。
- 个人提示仍发该用户申报时的群，明确企微用户ID、股票名/代码、规则/信号编号、参考价、仓位快照时间及修订。群成员可见本群提示，不能跨群投递。公共大模型分析仍是原有共享结果；个人提示为确定性本地逻辑，额外模型调用0次。
- 没有仓位记录不视为空仓；没有规则信号不凭空产生买卖建议。群内对话模型通过工具读取本人仓位与最近5个自然日的已落库信号，再解释工具事实。
- PERSONAL_POSITION复用notify_record独立消息类型，信号+群+用户+仓位修订摘要幂等，随公共信号事务一起提交；payload冻结，不随重试改写，后续申报可能使旧快照过时，消息已注明。
- 15分钟有效期、最多3次已知失败重试、UNKNOWN不自动重发，沿用机器人单长连接与允许群白名单。
- 全局删除关注保留仓位及个人仓位待发通知，不取消个人提示；也不会自动将空仓股票从公共名单移除。

## 4. 校验与边界

真实回调绑定身份，模型不能传user_id或group；写操作每消息一次、消息摘要去重、数量与价格须对应本条原文，不从历史补数。问句、否定、代他人和假设拒绝；数量0～10亿，可卖0～持股数量，正持仓成本>0且最多4位小数。无账号总资金字段，不能计算资产占比、风控预算或推荐下单股数。保留原规则与日线收盘确认；Python不接触业务数据库。

可执行只读SQL（不显示用户身份）：

```sql
SELECT symbol,count(*) AS records FROM personal_position GROUP BY symbol;
SELECT status,count(*) FROM notify_record WHERE message_type='PERSONAL_POSITION' GROUP BY status;
```
