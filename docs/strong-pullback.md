# 强势股缩量回踩：两阶段策略

## 早晚候选汇总（2026-10-21最新调整）

按用户确认，交易日09:40、15:30各推送一份全市场缩量回踩候选，最多5只。早晚同一股票仍可重复推荐，同一时间槽按目标群幂等；不再盘中每10分钟推送。

日线依据、原两阶段策略及前20只分钟确认上限保持。后台数据准备和失败任务每10分钟检查保持原交易时段；盘中转强即时提醒及15:30日报保持。晚间汇总不等于用当日收盘重算，具体日线依据见消息日期。

PULLBACK_DIGEST_ENABLED开关和V11队列表继续复用，最多3次已知失败重试、UNKNOWN不自动重发、时间槽10分钟有效期保持；投递窗口为09:40～09:50、15:30～15:40（结束时刻不含）。错过调度或过期汇总不补发，休市不推送。此处10分钟是投递有效期与后台数据检查频率，不是候选推送频率。

GET /api/v1/pullback的recommendations现返回frequencyPerTradingDay=2、times=[09:40,15:30]、maxCandidates、timezone、slots及enabled；不再返回intervalMinutes=10，避免误导。候选汇总不额外逐股调用模型。详情见[调度调整](pullback-twice-daily.md)。


用户于2026-10-21确认初始参数。参数尚未回测，不代表已验证收益。

## 数据与职责

Java筛选、保存观察池、生成规则信号和通知；Python提供行情及已有MA20指标。不改变原SWING_TREND_V1和INTRADAY_V1规则。新表通过V10迁移建立，旧迁移不修改。

第一阶段复用后台沪深ACTIVE股票筛选：排除ST、当前无成交、历史不足121条，最近20日不复权均成交额至少1亿元。前复权序列计算以下条件：

1. 从最新收盘向前计算连续严格下跌天数，要求2～5天，平盘结束连续段。
2. 回调开始前一日为锚点；锚点收盘较其20个交易记录前的收盘上涨至少15%。
3. 锚点及此前共20个交易日的最高价为近期高点；最新收盘相对该高点回撤3%～8%，边界包含。
4. 回调期间平均成交量不超过回调前5个交易日均量的70%；涉及日期成交量必须大于0。
5. 最新MA20严格高于上一日MA20，最新收盘严格高于MA20。

仅入观察池，不新增用户关注，不发转强通知。保存参数、版本、日线依据与不复权前日高点；同股票/依据日/参数版本重复入池不改原快照。

第二阶段只监控依据日恰为上一开市日的池中股票。完整分钟收盘严格突破前日不复权最高价，且成交量至少为此前20个连续完整分钟均量的1.5倍。沿用分钟身份、单位、新鲜度、交易时段和连续窗口校验，不跨午休拼量能。缺20分钟窗口时等待。

触发`STRONG_PULLBACK_V1 / PULLBACK_STRENGTH`，信号、规则明细、通知队列原子提交，同候选只触发一次。过期候选不再监控，参数变化使用新版本。

## 消耗与配置

全市场仅进行后台日线筛选，首次补历史会慢。分钟监控优先处理用户关注，再处理流动性排序前20只观察候选；相同股票只取一次分钟数据。默认每分钟尝试，任务互斥，源超时可能令单轮超过一分钟；不承诺每只股票每分钟都有新鲜报价。模型只在规则信号产生后分析，不逐股逐分钟调用。

配置见`.env.example`中的`PULLBACK_*`；调整后重启生效，池上限1～100。默认关闭，本机授权启动脚本开启。数据库不保存密钥。

## API契约

`GET /api/v1/pullback`：返回`parameters`、`version`、`pool`。池元素包括symbol、dataDate、version、averageAmount、referenceHigh、details、lastBarAt、triggeredAt。查询不触发行情、模型或发送消息；关闭时pool为空。详情中的context价格为前复权，referenceHigh为不复权。

`GET /api/v1/signals?type=PULLBACK_STRENGTH`：查询第二阶段已落库信号。

`POST /api/v1/screening/retry`：仅重开当前开市日已失败的筛选，重置FAILED及缺当日报价的项目，不重复处理已完成项目；返回`accepted`。不改历史日报、不直接发送群消息。

## 日报与行情修复

腾讯`newfqkline`作为日线后备，主源连续失败3次后熔断5分钟。保留所请求复权序列；成交额万元转元，SH688成交量已为股，其余支持股票手转股。Java要求新源覆盖已有其他来源的全部日期后才写入，避免局部替换导致混源。缺少成交额、身份错误或复权缺失均拒绝。当天日线仍须人工收盘确认。

日报增加涨跌家数结论、关注股相对沪指表现、实际MA20与量能、未满足的具体规则和独立回踩池。失败或覆盖不足明确标注，不降低筛选标准填充推荐。09:35只启动筛选；15:30发送日报。

## 通知显示与模型

通知从股票目录查询中文名，显示“亨通光电 600487”。启动脚本启用信号分析DeepSeek，密钥取环境变量。仅已提交规则信号调用模型；通知等待成功/失败记录，最多35秒后仍可发送规则内容，避免模型故障阻断提醒。已发送payload保留，不追改历史群消息。DeepSeek禁用thinking以控制响应时间，兼容其他模型时维持原请求。
